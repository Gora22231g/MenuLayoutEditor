# Проверка Menu Layout Editor 1.3.0

Проверка проведена по приложенному списку правил, без пункта reject-vibecoded. Это проверка исходников и сборки, а не одобрение модераторов Geode. Полный прогон в Geometry Dash не выполнен.

## Конкретные исправления

1. Добавлены обязательные графические/текстовые метаданные и теги, проверенные через официальный API Geode.
2. Части больше не добавляются непосредственно в исходные CCMenu. Собственные контейнеры повторяют преобразование родительского меню.
3. Удалённые сторонним модом элементы нельзя выбрать/разрезать; callback части проверяет существование и активность оригинала.
4. Исправлено достижение лимита 64 частей: обрезка с заменой одной части разрешена, увеличение сверх лимита отклоняется.
5. Один снимок используется для всех частей исходного элемента; добавлена проверка пиксельного бюджета перед выделением текстуры.
6. Исправлен перенос старых сохранений: в matjson отсутствие поля при неконстантном operator[] создаёт объект, а не null. Теперь наличие parts проверяется через contains до миграции. Ошибку обнаружил регрессионный тест.
7. Проверка исходников SDK показала, что Mod::saveData() логирует часть ошибок записи, но возвращает Ok. Новый основной файл записывается через writeStringSafe, его результат проверяется до изменения состояния в памяти.
8. Import CFG проверяет данные до применения и оставляет возможность Cancel. Export CFG не включает флаг прохождения гайда. Файловый callback использует WeakRef, чтобы не обращаться к закрытому редактору.
9. Отключены предкомпилированные заголовки только для цели мода: MSVC 19.44 аварийно завершался при новой комбинации шаблонов/PCH. Оптимизация Release сохранена.

## Проверка API

Имена и сигнатуры сверены с локально загруженным официальным SDK 5.10.1 и bindings 2.2081: CCMenuItemSpriteExtra::create, CCRenderTexture::create/beginWithClear/end, CCGLProgram, CCAffineTransformConcat, Mod::getSaveDir, file::pick, async::spawn, file::writeStringSafe, WeakRef::lock, matjson::parse/contains. Сборка и линковка дополнительно проверяют наличие используемых символов. Это подтверждает существование API, но не заменяет проверку правильности всех вызовов в игре.

## Что ещё проверить до подачи в каталог

- Пройти гайд и полностью перезапустить игру; проверить, что он не повторяется.
- Открыть диалоги Import/Export и проверить отмену диалогов, ошибку записи, импорт чужой раскладки и Cancel.
- Разрезать кнопку, сохранить, перезапустить игру, нажать обе части и восстановить исходник.
- Проверить изменение разрешения, масштаба и работу совместно с используемыми модами меню.
- Проверить динамические узлы и элементы без ID. Для последних пока остаётся путь с индексами: при изменении дерева меню сопоставление может измениться.
- Подготовить репозиторий или приватный доступ к исходникам для проверяющих. GitHub удобен, но публичный репозиторий именно на GitHub не обязателен.

Обход модерации или «неопределимость происхождения кода» не проверялись и не обещаются.
