Menu Layout Editor 1.3.0 — проверка 24.09.2026
Авторы: Gora22231g, Igch7.

Выполнено:
- Release x64 собран MSVC 19.44, Geode SDK 5.10.1, GD bindings 2.2081.
- CTest: 3/3 PASS (layout-geometry, layout-config, layout-guide-shader).
- Геометрия: разрезы, обрезка, прилипание, ограничения частей и памяти снимков.
- Конфиги: экспорт/импорт JSON, миграция старой раскладки, сохранение флага гайда,
  отклонение неверных версий, чисел, структуры, чрезмерного размера и глубины.
- Шейдер размытия скомпилирован и выполнен в OpenGL 4.6.0:
  прозрачная область RGB 0,255,0; размытая область RGB 61,61,61.
- Основное хранилище menu-layout.json записывается через проверяемый writeStringSafe.
- API файловых диалогов и сохранений сверены с исходниками SDK.
- В собственных src/ и tests/ нет поясняющих очевидное комментариев.

Не выполнено:
- Установка и проверка в запущенной Geometry Dash.
- Проверка полного гайда, настоящих файловых диалогов и сохранения после перезапуска GD.
- Проверка разрезов, обрезки, пересылки нажатий и совместимости с другими модами в игре.

Для проверки в игре:
1. Пройти Settings → Graphics → Menu Editor, перезапустить игру: гайд не повторяется.
2. Проверить Skip / Esc и сохранение признака завершения.
3. Проверить Snap, Cut V/H, Crop, Restore, Reset all, Save/Cancel и защиту RobTop.
4. Экспортировать CFG, изменить меню, импортировать CFG, сохранить и перезапустить игру.
5. Проверить отмену импорта, неверный JSON и кнопку Save folder.
6. Проверить авторов, иконку и описание на странице мода.

Подробности проверки правил и ограничения: AUDIT.md.
